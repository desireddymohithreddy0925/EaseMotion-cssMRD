# Hover Pagination - Dark Mode

A fully responsive, dark-mode themed pagination component with smooth hover animations using pure CSS.

## Features
- Pure CSS/HTML (no JS)
- Dark mode aesthetics with glowing active state
- Smooth hover transitions and micro-interactions
- Responsive design (adapts to mobile screens)
- Accessibility ready (aria labels, keyboard focusable)
- Respects `prefers-reduced-motion`

## Usage
Simply copy the HTML structure from `demo.html` and styles from `style.css` into your project.
